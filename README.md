# Volleyball Statistics

Offline-fähige Web-App (PWA) zur Erfassung und Auswertung von Volleyball-Ballberührungen.

## Starten (Entwicklung)
1. Ordner in VS Code öffnen.
2. Rechtsklick auf `index.html` → „Open with Live Server".

Beim Entwickeln (localhost) ist der Service Worker absichtlich aus, damit Änderungen sofort sichtbar sind.

## Online / installieren
Über GitHub Pages: https://grantelbart2020.github.io/volleyball-stats/
Am Handy in Chrome öffnen → Menü → „App installieren".
