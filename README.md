# Volleyball Statistics

Offline-fähige Web-App (PWA) zur Erfassung und Auswertung von Volleyball-Ballberührungen.

## Starten (Entwicklung)
1. Ordner in VS Code öffnen.
2. Rechtsklick auf `index.html` → „Open with Live Server".

- Meilenstein 0: Startseite, Sprache DE/EN, Hell/Dunkel
- Meilenstein 1a: Kreismenü-Prototyp (Testbildschirm, noch ohne Speicherung)
